# deep-research

Multi-source, citation-backed research. Fans out parallel web searches, keeps only authoritative sources, and writes a decision-grade brief where every claim carries a footnote.

> **Transparency**
>
> An original skill by Silicon Valley Academy.

## Install

Paste this into Claude Code:

```
Install the deep-research skill from github.com/sva-admin/deep-research
```

## Use it

```
Deep research: is Postgres or SQLite the right call for our offline-first app?
Deep dive on the state of AI video generation pricing
Investigate why our category's CAC doubled this year
```

You get two files: a raw source dump you can audit, and a brief with TL;DR, key findings, tensions between sources, what is still missing, and a clearly labeled recommendation. The point is the citations. If a finding has no footnote, it does not ship.
